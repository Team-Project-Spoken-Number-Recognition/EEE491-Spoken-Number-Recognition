# Simulation evidence

| Folder | Content | Naming |
|---|---|---|
| `results/<block>/` | Simulation logs with `TB_RESULT` lines | `<block>_<testID>_<YYYY-MM-DD>.log` |
| `waveforms/<block>/` | Waveform screenshots / exported `.wcfg` used in reports and demos | `<block>_<testID>_<YYYY-MM-DD>.png` |
| `reference_data/<block>/` | Input/expected vectors generated by MATLAB | `<block>_<name>.txt` / `.coe` |

Every evidence file must be traceable to a commit hash (write it into the log header or file name).
